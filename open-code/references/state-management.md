# State Management

UNIFIED PROJECT STATE VECTOR: Centralized global state vector: `S = { objective, project_model, architecture, repo_topology, dependency_graph, interface_contracts, system_constraints, hypothesis_registry, empirical_evidence, project_map, workstream_dag, task_ownership_matrix, execution_states, telemetry_memory, failure_cache, open_invariants, strategy_vector, dispatch_history, workspace_root, completion_vector }`. State transitions are strictly monotonically progressive upon receipt of validated telemetry. Atomic broadcast of updated state contexts to relevant agents; strict zero-stale-state evaluation invariant.

HYPOTHESIS ENGINE & EPISTEMIC STATE TRACKING: Epistemic uncertainty resolved via formal hypothesis lifecycle: `GENERATED → PRIORITIZED → INVESTIGATED → {SUPPORTED | REJECTED | UNRESOLVED}`. Concurrent maintenance of competing hypotheses under ambiguous symptoms. Empirical observations drive Bayesian belief updates. Rejected hypotheses committed to immutable Failure Memory; duplicate exploration of invalidated parameter space is prohibited without novel empirical priors.

ADAPTIVE STRATEGY & FAILURE MEMORY ACCUMULATION: Dynamic strategy recalibration triggered by empirical falsification, architectural discovery, and unexpected runtime states. Structured failure vector: `ATTEMPT → RESULT → INTERPRETATION → INVALIDATED ASSUMPTION → NEW EVIDENCE → NEXT STRATEGY`. Blocked pathways trigger dependency graph re-evaluation, hypothesis branching, or architectural reassessment. Zero retries on dead-ends without justified parameter mutation.

ATOMIC & ITERATIVE STATE MANAGEMENT: Discrete-event state machine: `av0x00` executes atomic state updates post-telemetry ingestion (updating topology, DAG states, agent status vectors, hypothesis confidence, and strategic path). Monotonic state advancement strictly driven by verified empirical evidence. Zero task dispatching against invalidated assumptions or unconfirmed execution states.
