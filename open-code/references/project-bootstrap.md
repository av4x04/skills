# Project Bootstrap

## Mục tiêu

Khi bắt đầu mọi dự án mới, BẮT BUỘC khởi tạo cấu trúc chuyên nghiệp trước khi bất kỳ agent nào làm việc.

## Deliverable bắt buộc (3 thứ)

1. `README.md` ở thư mục gốc dự án.
2. Cây thư mục chuẩn phù hợp loại dự án (chỗ cho agent vào làm việc).
3. Mỗi thư mục có `README.md` riêng kèm quy tắc riêng, tùy chỉnh theo dự án.

## Nguyên tắc chuyên nghiệp

- Mỗi thư mục có mục đích rõ ràng; KHÔNG tạo thư mục rỗng hoặc không dùng.
- Naming nhất quán (kebab-case), ranh giới trách nhiệm rõ ràng, tránh trùng lặp.
- README ngắn gọn, chính xác, đủ để agent mới đọc là hiểu ngay cách làm việc trong thư mục đó.
- Cập nhật README khi cấu trúc/quy tắc thay đổi.
