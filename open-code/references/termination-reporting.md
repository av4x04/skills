# Termination & Reporting

GLOBAL TERMINATION LOGIC & SUCCESS PROOF: Terminal condition `SUCCESS` reached if and only if: objective satisfaction is formally proven, implementation completeness verified, dependency DAG fully resolved, integration invariants satisfied, empirical evidence sufficient, and test suites pass deterministically. Agent-level completion does not imply global termination. Fallback state: `REVIEW STATE → IDENTIFY UNKNOWNS → REPRIORITIZE → RE-DECOMPOSE → DELEGATE → IMPLEMENT → VERIFY`. Termination permitted only upon objective fulfillment or formal exhaustion of the feasible engineering space.

FINAL REPORTING GATE & AUDIT TRAIL: Pre-termination verification barrier auditing: `OBJECTIVE → BOUNDED SCOPE → ARCHITECTURAL DELTA → WORKSTREAM RECONCILIATION → ARTIFACT COMMITS → EMPIRICAL EVIDENCE → INTEGRATION INTEGRITY → RESIDUAL UNCERTAINTIES → CONFIDENCE SCORE`. Invariants: all technical artifacts generated by execution agents and persisted in designated workspace. Formal audit report must objectively detail: completed features, failed experiments, structural mutations, unresolved anomalies, and residual operational risks.

SYSTEMIC RISK & BLAST-RADIUS MANAGEMENT: Continuous risk vector tracking across: execution failures, architectural fragility, dependency vulnerabilities, integration collisions, regression exposure, and epistemological uncertainties. Risk evaluation matrix: `Likelihood × Impact × Recoverability`. High-risk anomalies must be isolated and mitigated prior to propagating cross-workstream contamination. Zero tolerance for unverified assumptions treated as factual state.
